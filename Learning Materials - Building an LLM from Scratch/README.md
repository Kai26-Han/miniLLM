# Learning Materials: Building an LLM from Scratch

This collection explains how modern large language models are designed, trained, aligned, evaluated, and deployed. The chapters progress from intuition and fundamentals to architecture, algorithms, and hands-on miniLLM training workflows.

## Recommended Learning Path

1. Begin with the two conceptual overviews.
2. Study tokenization and the from-scratch GPT implementation.
3. Learn the major architecture choices.
4. Work through the pretraining, SFT, and RL algorithms.
5. Use the hands-on guides to run the corresponding miniLLM pipelines.
